# Evaluation of a Generative AI System for Localized Climate Awareness and Behavioral Change

## Overview
This project evaluates a Generative AI–based system designed to generate localized, audience-specific climate awareness content. It focuses on improving communication clarity, relevance, and encouraging sustainable behavioral change through personalized messaging.

## Problem Statement
Current climate communication systems are often generic and fail to address regional, cultural, and language differences. This leads to:
- Low engagement and understanding  
- Limited behavioral impact  
- High effort for manual customization  
- Poor scalability  

## Objectives
- Analyze the role of Generative AI in climate communication  
- Design a system for localized content generation  
- Evaluate readability, relevance, and effectiveness  
- Measure behavioral impact  

## Proposed Solution
A Generative AI–driven system that:
- Generates region-specific climate reports  
- Adapts content based on user context  
- Uses structured prompt engineering  
- Produces human-readable outputs  

## Features
- Localized climate content generation  
- Audience-aware messaging  
- AI-based prompt engineering  
- Readability and relevance evaluation  
- Behavioral impact analysis  

## Technology Stack

### Frontend
- React: Component-based UI development for interactive interfaces  
- JavaScript: Handles UI logic, API calls, and data processing  

### Backend
- Node.js: Server-side runtime for handling API requests and communication  
- Python: AI processing, backend scripts, and model interaction  

### Database and Authentication
- Firebase Authentication: Secure user login and session management  
- Firebase Firestore: NoSQL database for storing user data and climate reports  

### AI and Processing
- Google Gemini API: Generates climate awareness content  
- Prompt Engineering: Structured prompts for localized, audience-specific outputs  

### Maps and Visualization
- Leaflet: Used for interactive map-based visualization  

## Methodology
1. Data Collection: Climate and regional datasets  
2. Prompt Design: Structured prompts for targeted generation  
3. Model Integration: Use of Generative AI APIs  
4. Content Generation: Region-specific outputs  
5. Evaluation: Readability, relevance, and behavioral impact  

## Expected Outcomes
- Functional prototype system  
- Improved localized climate communication  
- Insights into AI-driven behavioral change  
- Scalable solution for real-world use
